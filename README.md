# IPA_Downloader
[![English README](https://img.shields.io/badge/README-English-blue.svg)](README_EN.md)  
Скрипт для загрузки приложений, приобретённых ранее в App Store, включая удалённые (работает на базе [ipatool-cpp](https://github.com/Sorvigolova/ipatool)).

## Информация о скрипте:
### Важно:
ipatool является неофициальным инструментом; следовательно, использование скрипта – только на свой страх и риск.
### Общие требования для использования:
* Windows 7-11 (x64)
* macOS начиная с 10.15 Catalina (поддерживается работа на процессорах Apple Silicon и Intel)
* Linux (x64 и ARM64: Arch Linux, Ubuntu, Debian, Fedora и другие)
* Стабильное интернет-соединение
* Аккаунт Apple с ранее загруженными приложениями
### Возможности скрипта:
#### IPA_Downloader (загрузка и установка приложений):
* Поиск приложений по названию или ID и покупка (без загрузки)
* Поиск приложений по названию или ID и загрузка последней версии
* Поиск приложений по названию или ID и загрузка (с выбором версии)
* Выбор списка приложений и покупка (без загрузки):
1. Список популярных приложений
2. Список популярных приложений, не приобретенных скриптом
3. Пользовательский список приложений
* Выбор списка приложений и загрузка последней версии:
1. Список популярных приложений
2. Список приложений из истории покупок аккаунта Apple
3. Список приложений, установленных на устройстве
4. Список сгруженных приложений, установленных на устройстве
5. Пользовательский список приложений
* Выбор списка приложений и загрузка (с выбором версии):
1. Список популярных приложений
2. Список приложений из истории покупок аккаунта Apple
3. Список приложений, установленных на устройстве
4. Список сгруженных приложений, установленных на устройстве
5. Пользовательский список приложений
* Проверка минимальной версии iOS для приложений в папке Apps
* Установка приложений из папки Apps

#### IPA_Installer (только установка приложений):
* Проверка минимальной версии iOS для приложений в папке Apps
* Установка приложений из папки Apps

#### Примечание:
* Все действия после ввода команд подтверждаются нажатием клавиши Enter
* Для загрузки приложений они должны быть приобретены в App Store ранее
* Загрузка приложений осуществляется из App Store
* Рекомендуется отключить использование аппаратных ключей безопасности и перейти на метод двухфакторной аутентификации (2FA)
* Скрипт поддерживает массовую покупку/загрузку/установку приложений, достаточно ввести порядковые номера (№) приложений/версий из таблиц через запятую или дефис, например, введя 1, 2, 3-5 произойдет покупка/загрузка/установка приложений с порядковыми номерами (№) 1, 2, 3, 4 и 5
* Доступно создание пользовательского списка приложений, достаточно добавить данные в формате `Название приложения: его ID`, например: `Google: 284815942` в файл Files/AppsListCustom.txt
* Режим IPA_Installer (только установка приложений) работает без авторизации

## Использование на Windows:
### Требования для Windows:
* Для установки загруженных приложений через скрипт требуется драйвер `AppleMobileDeviceSupport64` (входит в состав iTunes):  
- [Загрузить iTunes с сайта Apple](https://www.apple.com/itunes/download/win64)
* Вместо полной установки iTunes можно выполнить выборочную установку `AppleMobileDeviceSupport64.msi`, распаковав установщик iTunes любым архиватором (например: [7-Zip](https://www.7-zip.org))
* Скрипт работает без данного драйвера, однако он требуется для установки загруженных приложений на устройство

* Запустите файл UpdRootsCert.exe
* Отметьте флажки: Корневые сертификаты системы, Добавить ежемесячную задачу в Планировщик заданий
* Нажмите кнопку Установить
#### 2. Установите .NET Framework 4.8:
* Загрузите файл NDP48-x86-x64-AllOS-ENU.exe по ссылке:
- [Загрузить .NET Framework 4.8](https://go.microsoft.com/fwlink/?linkid=2088631)
* Запустите файл NDP48-x86-x64-AllOS-ENU.exe
* Установите .NET Framework 4.8 следуя инструкциям мастера установки
#### 3. Установите обновление KB3191564/KB3191566 (для добавления поддержки PowerShell 5.1):
* Загрузите обновление KB3191564/KB3191566 по ссылке:
- [Загрузить KB3191566 для Windows 7](https://download.microsoft.com/download/6/f/5/6f5ff66c-6775-42b0-86c4-47d41f2da187/Win7AndW2K8R2-KB3191566-x64.zip)
- [Загрузить KB3191564 для Windows 8.1](https://download.microsoft.com/download/6/f/5/6f5ff66c-6775-42b0-86c4-47d41f2da187/Win8.1AndW2K12R2-KB3191564-x64.msu)
* После загрузки KB3191566 для Windows 7 дополнительно распакуйте архив Win7AndW2K8R2-KB3191566-x64.zip
* Запустите файлы: Win7AndW2K8R2-KB3191566-x64.msu (для Windows 7) или Win8.1AndW2K12R2-KB3191564-x64.msu (для Windows 8.1)
* Установите обновление KB3191564/KB3191566 следуя инструкциям мастера установки
#### 4. Установите обновление KB2999226:
* Загрузите обновление KB2999226 по ссылке:
- [Загрузить KB2999226 для Windows 7](https://download.microsoft.com/download/1/1/5/11565a9a-ea09-4f0a-a57e-520d5d138140/Windows6.1-KB2999226-x64.msu)
- [Загрузить KB2999226 для Windows 8.1](https://download.microsoft.com/download/9/6/f/96fd0525-3ddf-423d-8845-5f92f4a6883e/Windows8.1-KB2999226-x64.msu)
* Запустите файлы: Windows6.1-KB2999226-x64.msu (для Windows 7) или Windows8.1-KB2999226-x64.msu (для Windows 8.1)
* Установите обновление KB2999226 следуя инструкциям мастера установки
#### 5. Перезагрузите ПК/ноутбук

### Как использовать (Windows):
#### 1. Распакуйте архив IPA_Downloader.zip любым архиватором (например: [7-Zip](https://www.7-zip.org))
#### 2. Дважды кликните по файлу Start_IPA_Downloader_Windows.bat
#### 3. При первом запуске потребуется первоначальная настройка:
* Выберите язык
* Нажмите Enter
* При наличии обновления выберите: перейти в репозиторий для загрузки новой версии скрипта или продолжить работу с текущей версией
* Нажмите Enter
#### 4. По умолчанию скрипт запускается в режиме IPA_Downloader (загрузка и установка приложений):
* Для авторизации введите команду: 1. Войти в аккаунт Apple
* Нажмите Enter
* Введите аккаунт Apple (Enter email:)
* Нажмите Enter
* Введите пароль (Enter password:)
* Нажмите Enter

* Если код двухфакторной аутентификации (2FA) автоматически не пришел, то на устройстве включите режим полета, перейдите по пути: `Настройки - Аккаунт Apple - Вход и безопасность - Получить код проверки` (это и есть код двухфакторной аутентификации (2FA)) 
* Введите код двухфакторной аутентификации (Enter 2FA code:)
* Нажмите Enter
* Введите необходимую команду
* Нажмите Enter

## Возможные ошибки и их решение:
### Расшифровка ошибок:
**1. Обработка `-File ./IPA_Downloader.ps1` завершилась сбоем: Access to the path is denied (macOS):**  
Включите Терминалу доступ по пути: `Системные настройки - Конфиденциальность и безопасность - Доступ к диску`.

**2. Не приходит код двухфакторной аутентификации (2FA) или проблемы с авторизацией:**  
Неверно введен пароль.  
Попробуйте войти с аккаунтом Apple на сайте `icloud.com`

**3. Login error: failed to initialize SAP signer: curl: Timeout was reached:**  
Не удалось подключиться к SAP, проверьте ваше интернет-соединение.

**4. Error: account is disabled:**  
Аккаунт Apple временно заблокирован Apple (обычно из-за многократных попыток ввода неверных данных пароля или кода 2FA).  
Требуется разблокировка аккаунта через устройство или на сайте `icloud.com`

**5. Download error: invalid response: empty songList:**  
Необходимо заново авторизоваться в скрипте с аккаунтом Apple.

**6. Download error: HTTP request failed: Couldn't resolve host name:**  
Не удалось подключиться к серверам Apple, проверьте ваше интернет-соединение.

**7. Download error: HTTP request failed: Timeout was reached:**  
Не удалось подключиться к серверам Apple, проверьте ваше интернет-соединение.

**8. Error: license is required:**  
Приложение не было приобретено на этом аккаунте Apple ранее.

**9. Purchase error: app not found:**  
Покупка приложения не удалась, так как приложение удалено из App Store.

**10. Purchase error: item is temporarily unavailable:**  
Приложение не было приобретено на этом аккаунте Apple ранее.  
Покупка не удалась, так как приложение удалено из App Store.

**11. Error: This Apple Account is temporarily unable to be used in the iTunes Store because it could not be found. Try again later:**  
Необходимо совершить любую бесплатную покупку в App Store.

**12. No device found:**  
Устройство не найдено.  
Убедитесь, что драйвер AppleMobileDeviceSupport64 установлен.

**13. Could not connect to lockdownd:**  
Проблемы с подключением к устройству Apple.  
Удалите iTunes и AppleMobileDeviceSupport64, затем удалите нижеуказанные папки и установите iTunes или AppleMobileDeviceSupport64 заново.  

```
C:\ProgramData\Apple\
C:\ProgramData\Apple\Apple Computer\
C:\Users\%username%\AppData\Local\Apple Computer\
C:\Users\%username%\AppData\Local\Apple Inc\
C:\Users\%username%\AppData\Roaming\Apple Computer\
```
Подключите устройство и нажмите `Доверять` при запросе `Доверять этому компьютеру?`

**14. WARNING: could not locate Payload/App.app/SC_Info/App.sinf in archive:**  
В устанавливаемом .ipa файле не найдена подпись приложения.

**15. ERROR: Install failed. Got error "APIInternalError" with code 0x00000000: Error Domain=IXErrorDomain Code=46:**  
Необходимо удалить приложение с устройства, перезагрузить устройство и попробовать установить приложение еще раз.

**16. После установки приложение сразу сворачивается при запуске:**  
Войдите в App Store под аккаунтом, с которого оно было загружено, и установите любое бесплатное приложение. После этого запустите проблемное приложение снова.

### При возникновении проблем:
#### Предоставьте, пожалуйста, следующую информацию:
* Используемая операционная система и версия IPA_Downloader
* Введите команду debug в главном меню скрипта, воспроизведите действие, приводящее к ошибке, и отправьте результат
* Скриншот ошибки
