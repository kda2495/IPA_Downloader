# IPA_Downloader

## Описание:
Скрипт, позволяющий загружать приложения из истории покупок Apple ID для установки на совместимые устройства (работает в связке с [IPATool](https://github.com/majd/ipatool)).

## Как использовать:
Кликаем 2 раза на !Start_IPA_Downloader.bat  

Скрипт запустится и предложит войти со своим аккаунтом Apple ID (если вход не осуществлен ранее), при этом необходимо сначала ввести Apple ID, затем пароль (INF enter password) и код двухфакторной аутентификации (INF enter 2FA code).  

Подтверждение всех действий в скрипте осуществляется нажатием клавиши Enter.  

<ins>**Обратите внимание, что пароль не показывается при вводе в целях безопасности.**</ins>  

После входа с Apple ID скрипт предложит на выбор несколько команд.  

**Описание команд скрипта:**
#### <ins>1.Поиск приложения и загрузка последней версии</ins>
Вводим название приложения для поиска.  
Для загрузки приложения необходимо ввести его ID (когда скрипт запросит "Введите ID приложения для загрузки").

## В чем плюсы данного скрипта в сравнении с iMazing?
Данный скрипт позволяет загрузить любые приложения, которые ранее загружались под Apple ID (даже недоступные в данный момент в российском регионе, либо удаленные из AppStore), а не только те, что видит iMazing (за определенное время).  
К примеру, некоторые приложения загружались мной еще в 2022 году, iMazing их не видит для установки, а данный скрипт дает возможность загрузить их и установить через 3uTools.
