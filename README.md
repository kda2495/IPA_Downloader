# IPA_Downloader
[![en](https://img.shields.io/badge/lang-en-red.svg)](https://github.com/kda2495/IPA_Downloader/blob/main/README.en.md)

PowerShell скрипт (для Windows) для загрузки ipa-файлов ранее загруженных приложений (работает в связке с [IPATool](https://github.com/majd/ipatool))  
## Описание
Cкрипт позволяет загружать приложения, которые ранее были загружены через Ваш AppleID (аналог iMazing) для дальнейшей установки на устройства (к примеру, через [3uTools](https://www.3u.com/)).
## Как использовать
Для работы со скриптом нужно войти со своим AppleID.  
Нажимаем на !Start_IPA_Downloader.bat  
Далее скрипт запустится и предложит войти со своим аккаунтом AppleID (если вход не осуществлен ранее), при этом необходимо сначала ввести данные AppleID, затем свой пароль (INF enter password) и код двухфакторной аутентификации (INF enter 2FA code).  
<ins>**Обратите внимание, что пароль не показывается при вводе в целях безопасности.**</ins>  
Затем скрипт предложит на выбор несколько команд.  

**Описание команд скрипта:**  
1.Поиск приложения и загрузка последней версии (если ранее уже вошли со своим AppleID)  
2.Ввод ID приложения и загрузка последней версии (если знаете ID приложения)  
3.Ввод ID приложения и загрузка (с выбором версии) (если знаете ID приложения)  
4.Вывод списка ID приложений и загрузка последней версии  
5.Вывод списка ID приложений и загрузка (с выбором версии)  
6.Отозвать данные своего AppleID

Поиск приложений ищет не все, легче всего найти ID приложения, зная его ссылку в AppStore (к примеру, ищем в поисковике приложение, находим ссылку в AppStore и нам из этой ссылки нужны числа, которые идут после id.

Далее приложения, загруженные через данный скрипт, можно установить через 3uTools (подключаем устройство, открываем 3uTools, заходим во вкладку Приложения, выбираем Установить IPA и находим файл приложения). 

## Загрузка более ранних версий приложения
В скрипте выбираем команды 3 или 5, вводим ID приложения, далее скрипт выдаст нам список версий через запятую (версии отсортированы от первой к последней), вводим нужную нам версию, после загрузки устанавливаем через 3uTools.

Важное замечание. Если приложение недоступно в Вашем регионе или удалено из AppStore, то при наличии обновления в AppStore оно будет отображаться, но при попытке обновления будет ошибка. Для обновления необходимо удалить старую версию приложения, загрузить новую версию через IPA_Downloader и установить через 3uTools.
