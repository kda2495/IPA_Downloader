# IPA_Downloader
[![English README](https://img.shields.io/badge/README-English-blue.svg)](README_EN.md)  
Скрипт для покупки/загрузки любых доступных в App Store приложений, а также восстановления удалённых - при условии, что они были приобретены ранее с вашей учетной записью Apple ID (работает на базе [ipatool-cpp](https://github.com/Sorvigolova/ipatool)).

## Возможности:
* Поиск приложения и покупка (без загрузки);  
* Поиск приложения и загрузка последней версии;  
* Поиск приложения и загрузка (с выбором версии);  
* Ввод ID приложений и покупка (без загрузки);  
* Ввод ID приложений и загрузка последней версии;  
* Ввод ID приложений и загрузка (с выбором версии);  
* Вывод списка приложений и покупка (без загрузки);  
* Вывод списка приложений и загрузка последней версии;  
* Вывод списка приложений и загрузка (с выбором версии);  
* Проверка минимальной версии iOS для приложений в папке Apps;  
* Установка приложений из папки Apps.  

#### Скрипт НЕ умеет:
* Загружать ранее **НЕ** приобретённые в App Store приложения;  
* Делать копию приложений прямо с устройства.  

#### Примечание:
* Все действия после ввода команд подтверждаются нажатием клавиши Enter;  
* Для покупки, загрузки приложений они должны быть приобретены заранее в App Store;  
* Загрузка приложений осуществляется из App Store.  

## Общие требования для использования:
* Windows 7, 8.1, 10, 11 (x64);  
* macOS (поддерживается работа на Apple Silicon и Intel);  
* Стабильное интернет-соединение;  
* Аккаунт Apple ID с ранее загруженными приложениями.  

## Для поддержки установки приложений (Windows):
* Драйвер AppleMobileDeviceSupport (входит в состав iTunes):  
[Ссылка для загрузки iTunes с сайта Apple](https://www.apple.com/itunes/download/win64)  
* Вместо полной установки iTunes можно выполнить выборочную установку AppleMobileDeviceSupport64.msi, распаковав установщик iTunes архиватором.  

## Для запуска на Windows 7 и 8.1:
#### Все действия выполняются строго в нижеуказанной последовательности:
#### 1. **Обновляем системные сертификаты через UpdRootsCert:**
* Переходим по ссылке для загрузки UpdRootsCert:  
[Ссылка для загрузки UpdRootsCert](https://disk.yandex.ru/d/SdHMgwJ55MTQRg)  
* Загружаем файл UpdRootsCert.exe;  
* Запускаем файл UpdRootsCert.exe;  
* Отмечаем флажки: Корневые сертификаты системы, Сертификаты Минцифры РФ, Добавить ежемесячную задачу в Планировщик заданий;  
* Нажимаем кнопку Установить.  

#### 2. **Устанавливаем .NET Framework 4.8:**
* Переходим по ссылке для загрузки .NET Framework 4.8:  
[Ссылка для загрузки .NET Framework 4.8](https://go.microsoft.com/fwlink/?linkid=2088631)  
* Загружаем файл NDP48-x86-x64-AllOS-ENU.exe;  
* Запускаем файл NDP48-x86-x64-AllOS-ENU.exe;  
* Устанавливаем .NET Framework 4.8 следуя инструкциям мастера установки.  

#### 3. **Устанавливаем обновление KB3191566 (для добавления поддержки PowerShell 5.1):**
* Переходим по ссылке для загрузки KB3191566:  
[Ссылка для загрузки KB3191566](https://www.microsoft.com/en-us/download/details.aspx?id=54616)  
* Нажимаем кнопку Download;  
* Отмечаем флажки: Win7AndW2K8R2-KB3191566-x64.zip (для Windows 7) или Win8.1AndW2K12R2-KB3191564-x64.msu (для Windows 8.1);  
* Нажимаем кнопку Download;  
* Загружаем файлы: Win7AndW2K8R2-KB3191566-x64.zip (для Windows 7) или Win8.1AndW2K12R2-KB3191564-x64.msu (для Windows 8.1);  
* Распаковываем архив Win7AndW2K8R2-KB3191566-x64.zip (для Windows 7);  
* Запускаем файлы: Win7AndW2K8R2-KB3191566-x64.msu (для Windows 7) или Win8.1AndW2K12R2-KB3191564-x64.msu (для Windows 8.1);

Полный набор вышеуказанных программ/обновлений для Windows 7/8.1 доступен по ссылке:

## Как использовать (Windows):
#### 1. **Распаковываем архив IPA_Downloader.zip любым архиватором;**  
#### 2. **Дважды кликаем по файлу Start_IPA_Downloader.bat;**
#### 3. **При первом запуске потребуется вход в Apple ID:**
* Вводим Apple ID (Enter email);  
* Вводим пароль (Enter password);  
* Вводим код двухфакторной аутентификации (Enter 2FA code).  
#### 4. **Вводим необходимую команду.**

## Для запуска на macOS:
#### Все действия выполняются строго в нижеуказанной последовательности:  
#### 1. **Устанавливаем PowerShell:**
* Переходим по ссылке для загрузки PowerShell:  
[Ссылка для загрузки PowerShell](https://github.com/PowerShell/PowerShell/releases)  
* Находим последний релиз PowerShell (на данный момент это 7.6.3);  
* Нажимаем Show all assets;  
* Загружаем файлы: powershell-7.6.3-osx-arm64.pkg (для Mac на Apple Silicon) или powershell-7.6.3-osx-x64.pkg (для Mac на Intel);  
* Производим установку powershell-7.6.3-osx-arm64.pkg (для Mac на Apple Silicon) или powershell-7.6.3-osx-x64.pkg (для Mac на Intel).  
#### 2. **Устанавливаем менеджер пакетов Homebrew:**
* Запускаем Терминал (Command + Пробел, затем ввести Терминал в поле поиска Spotlight);  
* В Терминале вводим: `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`  
* В процессе установки Homebrew, может потребоваться ввод пароля;  
* После установки Homebrew внизу Терминала появится текст ==> Next steps;  
* Необходимо поочередно ввести 3 команды (2 из них начинаются на echo и одна на eval).
#### 3. **Устанавливаем пакет minizip:**
* В Терминале вводим: `brew install minizip`
#### 4. **Устанавливаем пакет ideviceinstaller:**
* В Терминале вводим: `brew install ideviceinstaller`

## Как использовать (macOS):
#### 1. **Распаковываем архив IPA_Downloader.zip любым архиватором;**
#### 2. **В Терминале вводим:**
* `chmod +x ` (с пробелом после x) и перетаскиваем файл Start_IPA_Downloader.command на Терминал;  
* Дважды кликаем по файлу Start_IPA_Downloader.command;  
* В первый раз macOS заблокирует запуск Start_IPA_Downloader.command;  
* Нажимаем на файл Start_IPA_Downloader.command правой кнопкой мыши;  
* В контекстном меню выбираем Открыть;  
* Появится то же самое предупреждение, но в нём появится новая кнопка Открыть;  
* Нажимаем кнопку Открыть;  
* macOS запомнит ваш выбор, и в будущем скрипт будет запускаться обычным двойным кликом.  
#### 3. **При первом запуске потребуется вход в Apple ID:**
* Вводим Apple ID (Enter email);  
* Вводим пароль (Enter password);  
* Вводим код двухфакторной аутентификации (Enter 2FA code).  
#### 4. **Вводим необходимую команду.**

#### Примечание:
В случае, если скрипт не запускается, вводим в Терминале следующие команды:  
`brew reinstall minizip`  
`brew reinstall ideviceinstaller`

## Расшифровка ошибок:
* Download error: HTTP request failed: Timeout was reached - Не удалось подключиться к серверам Apple, проверьте Ваше интернет-соединение;  
* Error: license is required - Приложение не было приобретено на этом Apple ID ранее;  
* Purchase error: app not found - Покупка приложения не удалась, так как приложение удалено из App Store;  
* Purchase error: item is temporarily unavailable - Приложение не было приобретено на этом Apple ID ранее, покупка не удалась, так как приложение удалено из App Store;  
* No device found - Устройство не найдено. Убедитесь, что драйвер AppleMobileDeviceSupport64 установлен (актуально для Windows).
