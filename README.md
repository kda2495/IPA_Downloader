# IPA_Downloader
[![English README](https://img.shields.io/badge/README-English-blue.svg)](README_EN.md)  
Скрипт для покупки/загрузки любых доступных в App Store приложений, а также восстановления удалённых - при условии, что они были приобретены ранее с вашим аккаунтом Apple (работает на базе [ipatool-cpp](https://github.com/Sorvigolova/ipatool)).

## Информация о скрипте:
### Важно:
ipatool является неофициальным инструментом; следовательно, использование скрипта – только на свой страх и риск.
### Возможности скрипта:
#### IPA_Downloader (загрузка и установка приложений):
* Поиск приложений по названию или ID и покупка (без загрузки)
* Поиск приложений по названию или ID и загрузка последней версии
* Поиск приложений по названию или ID и загрузка (с выбором версии)
* Выбор списка приложений и покупка (без загрузки)
* Выбор списка приложений и загрузка последней версии
* Выбор списка приложений и загрузка (с выбором версии)
* Проверка минимальной версии iOS для приложений в папке Apps
* Установка приложений из папки Apps

#### IPA_Installer (установка приложений):
* Проверка минимальной версии iOS для приложений в папке Apps
* Установка приложений из папки Apps.

#### Скрипт НЕ умеет:
* Загружать ранее **НЕ** приобретённые в App Store приложения;
* Делать копию приложений прямо с устройства.

#### Примечание:
* Для загрузки приложений они должны быть приобретены в App Store ранее;
* Загрузка приложений осуществляется из App Store;
* Рекомендуется отключить использование аппаратных ключей безопасности и перейти на метод двухфакторной аутентификации;
* Скрипт поддерживает массовую покупку/загрузку/установку приложений, достаточно ввести порядковые номера (№) приложений/версий из таблиц через запятую или дефис, например, введя 1, 2, 3-5 произойдет покупка/загрузка/установка приложений с порядковыми номерами (№) 1, 2, 3, 4 и 5;
* Доступно создание пользовательского списка приложений, достаточно добавить данные в формате `Название приложения: его ID`, например: `Google: 284815942` в файл Files/AppsListCustom.txt.

### Общие требования для использования:
* Windows 7 - 11 (x64);
* macOS начиная с 10.15 Catalina (поддерживается работа на процессорах Apple Silicon и Intel);
* Linux (x64 и ARM64: Arch Linux, Ubuntu, Debian, Fedora и другие);
* Стабильное интернет-соединение;
* Аккаунт Apple с ранее загруженными приложениями.

## Использование на Windows:
### Требования для Windows:
* Для установки загруженных приложений через скрипт требуется драйвер `AppleMobileDeviceSupport64` (входит в состав iTunes):  
[Ссылка для загрузки iTunes с сайта Apple](https://www.apple.com/itunes/download/win64)
* Вместо полной установки iTunes можно выполнить выборочную установку `AppleMobileDeviceSupport64.msi`, распаковав установщик iTunes любым архиватором (7-Zip, WinRAR).
* Скрипт работает без данного драйвера, однако он требуется для установки загруженных приложений на устройство.

### Требования для Windows 7 и 8.1:
#### Все действия выполняются строго в нижеуказанной последовательности:
Загружаем полный набор программ/обновлений для Windows 7/8.1 по ссылке:  
[Ссылка для загрузки полного набора программ/обновлений](https://disk.yandex.ru/d/Fft0whzAz-C7Jg)  
#### 1. Обновляем системные сертификаты через UpdRootsCert:
* Запускаем файл UpdRootsCert.exe;
* Отмечаем флажки: Корневые сертификаты системы, Добавить ежемесячную задачу в Планировщик заданий;
* Нажимаем кнопку Установить.
#### 2. Устанавливаем .NET Framework 4.8:
* Запускаем файл NDP48-x86-x64-AllOS-ENU.exe;
* Устанавливаем .NET Framework 4.8 следуя инструкциям мастера установки.
#### 3. Устанавливаем обновление KB3191566 (для добавления поддержки PowerShell 5.1):
* Запускаем файлы: Win7AndW2K8R2-KB3191566-x64.msu (для Windows 7) или Win8.1AndW2K12R2-KB3191564-x64.msu (для Windows 8.1);
* Устанавливаем обновление KB3191566 следуя инструкциям мастера установки.
#### 4. Устанавливаем обновление KB2999226:
* Запускаем файлы: Windows7-KB2999226-x64 (для Windows 7) или Windows8.1-KB2999226-x64 (для Windows 8.1);
* Устанавливаем обновление KB2999226 следуя инструкциям мастера установки.

### Как использовать (Windows):
#### 1. Распаковываем архив IPA_Downloader.zip любым архиватором (7-Zip, WinRAR);
#### 2. Дважды кликаем по файлу Start_IPA_Downloader_Windows.bat;
#### 3. При первом запуске потребуется первоначальная настройка:
* Выбираем язык;
* Нажимаем Enter;
* При наличии обновления выбираем, перейти в репозиторий для загрузки новой версии скрипта или продолжить работу с текущей версией;
* Нажимаем Enter.
#### 4. По умолчанию скрипт запускается в режиме IPA_Downloader (загрузка и установка приложений):
* Для авторизации вводим команду: 1. Войти в аккаунт Apple;
* Нажимаем Enter;
* Вводим аккаунт Apple (Enter email:);
* Нажимаем Enter;
* Вводим пароль (Enter password:);
* Нажимаем Enter;
* На устройстве нажимаем Разрешить и запоминаем код двухфакторной аутентификации (2FA);
* Если код двухфакторной аутентификации (2FA) автоматически не пришел, то на устройстве включаем режим полета, переходим в `Настройки - Аккаунт Apple - Вход и безопасность - Получить код проверки` (это и есть код двухфакторной аутентификации (2FA)); 
* Вводим код двухфакторной аутентификации (Enter 2FA code:);
* Нажимаем Enter;
* Вводим необходимую команду;
* Нажимаем Enter.

## Использование на macOS:
### Требования для macOS:
### Все действия выполняются строго в нижеуказанной последовательности:
### При установке на Mac с процессорами Apple Silicon:
#### 1. Устанавливаем Xcode Command Line Tools:
* Запускаем Терминал (Command + Пробел, затем ввести `Терминал` в поле поиска Spotlight);
* Вводим в Терминал: `xcode-select --install`
* Нажимаем Enter.
#### 2. Устанавливаем менеджер пакетов Homebrew:
* Вводим в Терминал: `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`
* Нажимаем Enter;
* В процессе установки Homebrew, может потребоваться ввод пароля;
* После установки Homebrew внизу Терминала появится текст ==> Next steps.
* Вводим в Терминал:
```
echo >> ~/.zprofile
echo 'eval "$(/opt/homebrew/bin/brew shellenv zsh)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv zsh)"
```
* Нажимаем Enter.
#### 3. Устанавливаем пакеты ideviceinstaller, minizip и powershell:
* Вводим в Терминал: `brew install ideviceinstaller minizip powershell`
* Нажимаем Enter.
* При появлении запросов вводим `y` в Терминал и нажимаем Enter.
### При установке на Mac с процессорами Intel:
#### 1. Устанавливаем Xcode Command Line Tools:
* Запускаем Терминал (Command + Пробел, затем вводим `Терминал` в поле поиска Spotlight);
* Нажимаем Enter;
* Вводим в Терминал: `xcode-select --install`
* Нажимаем Enter.
#### 2. Устанавливаем менеджер пакетов MacPorts:
* Нажимаем на логотип Apple () в левом верхнем углу экрана, выбираем `Об этом Mac` и смотрим поле `macOS`;
* Загружаем установочный файл для своей версии macOS:  
[Ссылка для загрузки MacPorts](https://github.com/macports/macports-base/releases)
* Нажимаем `Show all assets` и ищем файл с расширением `.pkg` для своей версии macOS;
* Производим установку MacPorts с помощью установочного файла.
#### 3. Устанавливаем пакеты ideviceinstaller, minizip и powershell:
* Запускаем `новый` Терминал (Command + Пробел, затем вводим `Терминал` в поле поиска Spotlight);
* Вводим в Терминал: `sudo port install ideviceinstaller minizip powershell`
* Нажимаем Enter;
* При появлении запросов вводим `y` в Терминал и нажимаем Enter.
#### Примечание:
* Для удаления Homebrew и всех его компонентов, вводим в Терминал:  
`/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/uninstall.sh)"` и нажмите Enter.
* На macOS 10.15 Catalina необходимо установить PowerShell версии 7.3.12, загрузив файл:
[Ссылка для загрузки PowerShell 7.3.12](https://github.com/PowerShell/PowerShell/releases/download/v7.3.12/powershell-7.3.12-osx-x64.pkg)

### Как использовать (macOS):
#### 1. Распаковываем архив IPA_Downloader.zip любым архиватором (Keka);
#### 2. Дважды кликаем по файлу Start_IPA_Downloader_macOS.command;
* В первый раз macOS заблокирует запуск Start_IPA_Downloader_macOS.command;
* В появившемся окне `Файл "Start_IPA_Downloader_macOS.command" не был открыт` нажимаем `Готово`;
* Нажимаем на логотип Apple () в левом верхнем углу экрана и выбираем `Системные настройки`;
* В левой боковой панели прокручиваем вниз и выбираем вкладку `Конфиденциальность и безопасность`;
* Прокручиваем правую часть экрана вниз до раздела `Безопасность`;
* В пункте `Файл Start_IPA_Downloader_macOS.command заблокирован для защиты Вашего Mac` нажимаем на кнопку `Все равно открыть`;
* В появившемся окне `Открыть файл "Start_IPA_Downloader_macOS.command?` нажимаем `Все равно открыть`;
* Вводим пароль от вашего Mac или прикладываем палец к Touch ID.
#### 3. При первом запуске потребуется первоначальная настройка:
* Выбираем язык;
* Нажимаем Enter;
* При наличии обновления выбираем, перейти в репозиторий для загрузки новой версии скрипта или продолжить работу с текущей версией;
* Нажимаем Enter.
#### 4. По умолчанию скрипт запускается в режиме IPA_Downloader (загрузка и установка приложений):
* Для авторизации вводим команду: 1. Войти в аккаунт Apple;
* Нажимаем Enter;
* Вводим аккаунт Apple (Enter email:);
* Нажимаем Enter;
* Вводим пароль (Enter password:);
* Нажимаем Enter;
* На устройстве нажимаем Разрешить и запоминаем код двухфакторной аутентификации (2FA);
* Если код двухфакторной аутентификации (2FA) автоматически не пришел, то на устройстве включаем режим полета, переходим в `Настройки - Аккаунт Apple - Вход и безопасность - Получить код проверки` (это и есть код двухфакторной аутентификации (2FA)); 
* Вводим код двухфакторной аутентификации (Enter 2FA code:);

* Нажимаем Enter.

## Описание команд скрипта:

#### 1. Поиск приложений по названию или ID и покупка (без загрузки):
* Вводим название приложения или ID приложений для поиска;

* Вводим порядковые номера (№) приложений для покупки;
* Нажимаем Enter;
* Скрипт осуществит покупку выбранных приложений.

* В случае ввода ID приложений скрипт осуществит покупку указанных приложений.
#### 2. Поиск приложений по названию или ID и загрузка последней версии:
* Вводим название приложения или ID приложений для поиска;
* Нажимаем Enter;
* В случае ввода названия приложения отобразится список найденных приложений;
* Вводим порядковые номера (№) приложений для покупки;
* Нажимаем Enter;
* Скрипт осуществит загрузку выбранных приложений.

* В случае ввода ID приложений скрипт осуществит загрузку указанных приложений.

* Нажимаем Enter;
* Отобразится список ID версий приложения (от первой к последней);
* Вводим порядковые номера (№) ID версий или ID версий для отображения версий;
* Нажимаем Enter;
* Отобразится список версий приложения;
* Вводим порядковые номера (№) версий приложения для загрузки;

* Нажимаем Enter;

* Вводим порядковые номера (№) приложений для покупки;
* Нажимаем Enter;
* Скрипт осуществит покупку выбранных приложений.

3. Список приложений, установленных на устройстве

* Отобразится выбранный список;
* Вводим порядковые номера (№) приложения для загрузки;

## Возможные ошибки и их решение:
### Расшифровка ошибок:
* `Обработка -File ./IPA_Downloader.ps1 завершилась сбоем: Access to the path is denied (macOS)` - Включите Терминалу доступ по пути: `Системные настройки - Конфиденциальность и безопасность - Доступ к диску`.
* `Login error: failed to initialize SAP signer: curl: Timeout was reached.` - Не удалось подключиться к SAP, проверьте Ваше интернет-соединение.
* `Error: account is disabled` - Аккаунт Apple временно заблокирован Apple (обычно из-за многократных попыток ввода неверных данных пароля или кода 2FA), требуется разблокировка аккаунта через устройство или на сайте `icloud.com`
* `Download error: HTTP request failed: Couldn't resolve host name` - Не удалось подключиться к серверам Apple, проверьте Ваше интернет-соединение.
* `Download error: HTTP request failed: Timeout was reached` - Не удалось подключиться к серверам Apple, проверьте Ваше интернет-соединение.
* `Error: license is required` - Приложение не было приобретено на этом аккаунте Apple ранее.
* `Error: This Apple Account is temporarily unable to be used in the iTunes Store because it could not be found. Try again later.` - Необходимо совершить любую бесплатную покупку в App Store.
* `Purchase error: app not found` - Покупка приложения не удалась, так как приложение удалено из App Store.
* `Purchase error: item is temporarily unavailable` - Приложение не было приобретено на этом аккаунте Apple ранее, покупка не удалась, так как приложение удалено из App Store.
* `No device found` - Устройство не найдено. Убедитесь, что драйвер AppleMobileDeviceSupport64 установлен (актуально для Windows).
* `WARNING: could not locate Payload/App.app/SC_Info/App.sinf in archive!` - В устанавливаемом ipa файле не найдена подпись приложения.
* `ERROR: Install failed. Got error "APIInternalError" with code 0x00000000: Error Domain=IXErrorDomain Code=46` - Необходимо удалить приложение с устройства, перезагрузить устройство и попробовать установить еще раз.
* `Could not connect to lockdownd: Invalid HostID. Exiting.` - Удаляем нижеуказанные папки, затем удаляем iTunes, AppleMobileDeviceSupport64 и устанавливаем iTunes или AppleMobileDeviceSupport64 заново, подключаем устройство и нажимаем `Доверять` при запросе `Доверять этому компьютеру?`
```
C:\ProgramData\Apple\
C:\ProgramData\Apple\Apple Computer\
C:\Users\%username%\AppData\Local\Apple Computer\
C:\Users\%username%\AppData\Local\Apple Inc\
C:\Users\%username%\AppData\Roaming\Apple Computer\
```
* В случае проблем с авторизацией попробуйте войти со своим аккаунтом Apple на сайт `icloud.com`
* Если после установки приложение сразу сворачивается при запуске, войдите в App Store под аккаунтом, с которого оно было загружено, и установите любое бесплатное/платное приложение. После этого запустите проблемное приложение снова.

### При возникновении проблем:
#### Предоставьте, пожалуйста, следующую информацию:
* Используемая операционная система и версия IPA_Downloader;
* Введите команду debug в главном меню скрипта, воспроизведите действие, приводящее к ошибке, и отправьте результат;
* Скриншот ошибки.
