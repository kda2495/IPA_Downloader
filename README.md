# IPA_Downloader
[![English README](https://img.shields.io/badge/README-English-blue.svg)](README_EN.md)  
Скрипт для покупки/загрузки любых доступных в App Store приложений, а также восстановления удалённых - при условии, что они были приобретены ранее с вашим Аккаунтом Apple (работает на базе [ipatool-cpp](https://github.com/Sorvigolova/ipatool) и [ipatool-go](https://github.com/majd/ipatool).

## Возможности скрипта:
#### IPA_Installer:
* Проверка минимальной версии iOS для приложений в папке IPA_Downloader/Apps;
* Установка приложений из папки IPA_Downloader/Apps.
#### IPA_Downloader:
* Поиск приложения и покупка (без загрузки);
* Поиск приложения и загрузка последней версии;
* Поиск приложения и загрузка (с выбором версии);
* Ввод ID приложений и покупка (без загрузки);
* Ввод ID приложений и загрузка последней версии;
* Ввод ID приложений и загрузка (с выбором версии);
* Вывод списка приложений и покупка (без загрузки);
* Вывод списка приложений и загрузка последней версии;
* Вывод списка приложений и загрузка (с выбором версии);
* Проверка минимальной версии iOS для приложений в папке IPA_Downloader/Apps;
* Установка приложений из папки IPA_Downloader/Apps.

#### Скрипт НЕ умеет:
* Загружать ранее **НЕ** приобретённые в App Store приложения;
* Делать копию приложений прямо с устройства.

#### Примечание:
* Для загрузки приложений они должны быть приобретены в App Store ранее;
* Загрузка приложений осуществляется из App Store.

## Общие требования для использования:
* Windows 7, 8.1, 10, 11 (x64);
* macOS начиная с 10.15 Catalina (поддерживается работа на Apple Silicon и Intel);
* Linux (x64 и ARM64: Arch Linux, Ubuntu, Debian, Fedora и др.);
* Стабильное интернет-соединение;
* Аккаунт Apple с ранее загруженными приложениями.

## Для запуска на Windows:
### Требования для Windows:
* Установленный iTunes с сайта Apple (для поддержки установки приложений через скрипт):  
[Ссылка для загрузки iTunes с сайта Apple](https://www.apple.com/itunes/download/win64)
* Вместо полной установки iTunes можно выполнить выборочную установку AppleMobileDeviceSupport64.msi, распаковав установщик iTunes любым архиватором.

### Требования для Windows 7 и 8.1:
#### Все действия выполняются строго в нижеуказанной последовательности:
#### 1. Обновляем системные сертификаты через UpdRootsCert:
* Переходим по ссылке для загрузки UpdRootsCert:  
[Ссылка для загрузки UpdRootsCert](https://disk.yandex.ru/d/SdHMgwJ55MTQRg)  
* Загружаем файл UpdRootsCert.exe;
* Запускаем файл UpdRootsCert.exe;
* Отмечаем флажки: Корневые сертификаты системы, Добавить ежемесячную задачу в Планировщик заданий;
* Нажимаем кнопку Установить.

#### 2. Устанавливаем .NET Framework 4.8:
* Переходим по ссылке для загрузки .NET Framework 4.8:  
[Ссылка для загрузки .NET Framework 4.8](https://go.microsoft.com/fwlink/?linkid=2088631)  
* Загружаем файл NDP48-x86-x64-AllOS-ENU.exe;
* Запускаем файл NDP48-x86-x64-AllOS-ENU.exe;
* Устанавливаем .NET Framework 4.8 следуя инструкциям мастера установки.

#### 3. Устанавливаем обновление KB3191566 (для добавления поддержки PowerShell 5.1):
* Переходим по ссылке для загрузки KB3191566:  
[Ссылка для загрузки KB3191566](https://www.microsoft.com/en-us/download/details.aspx?id=54616)  
* Нажимаем кнопку Download;
* Отмечаем флажки: Win7AndW2K8R2-KB3191566-x64.zip (для Windows 7) или Win8.1AndW2K12R2-KB3191564-x64.msu (для Windows 8.1);
* Нажимаем кнопку Download;
* Загружаем файлы: Win7AndW2K8R2-KB3191566-x64.zip (для Windows 7) или Win8.1AndW2K12R2-KB3191564-x64.msu (для Windows 8.1);
* Распаковываем архив Win7AndW2K8R2-KB3191566-x64.zip (для Windows 7);
* Запускаем файлы: Win7AndW2K8R2-KB3191566-x64.msu (для Windows 7) или Win8.1AndW2K12R2-KB3191564-x64.msu (для Windows 8.1);
* Устанавливаем обновление KB3191566 следуя инструкциям мастера установки.

Полный набор вышеуказанных программ/обновлений для Windows 7/8.1 доступен по ссылке:  
[Ссылка для полного набора программ/обновлений](https://disk.yandex.ru/d/Fft0whzAz-C7Jg)  

### Как использовать (Windows):
#### 1. Распаковываем архив IPA_Downloader.zip любым архиватором;
#### 2. Дважды кликаем по файлу Start_IPA_Downloader.bat;
#### 3. При первом запуске потребуется первоначальная настройка:
* Выбираем язык;
* Нажимаем Enter;
* При наличии обновления выбираем, перейти на GitHub для загрузки новой версии скрипта или продолжить работу с текущей версией;
* Нажимаем Enter.
#### 4. По умолчанию скрипт запускается в режиме IPA_Installer:
* Вводим необходимую команду;
* Нажимаем Enter.
* Для перехода в режим IPA_Downloader необходимо ввести команду 5. Перейти в IPA_Downloader.
#### 5. После перехода в режим IPA_Downloader:
* Выбираем версию ipatool (ipatool-cpp или ipatool-go);
* Если выбрана версия ipatool-go, то вводим мастер-ключ, который необходимо запомнить, так как он будет запрашиваться при каждом запуске скрипта; 
* Нажимаем Enter;
* Вводим Аккаунт Apple (Enter email:);
* Нажимаем Enter;
* Вводим пароль (Enter password:);
* Нажимаем Enter;
* На устройстве нажимаем Разрешить и запоминаем код двухфакторной аутентификации (2FA);
* Если код двухфакторной аутентификации (2FA) автоматически не пришел, то на устройстве включаем режим полета, переходим в Настройки-Аккаунт Apple-Вход и безопасность-Получить код проверки (это и есть код двухфакторной аутентификации (2FA)); 
* Вводим код двухфакторной аутентификации (Enter 2FA code:);
* Нажимаем Enter;
* Вводим необходимую команду;
* Нажимаем Enter.

## Для запуска на macOS:
### Требования для macOS:
#### Все действия выполняются строго в нижеуказанной последовательности:
#### 1. Устанавливаем менеджер пакетов Homebrew:
* Запускаем Терминал (Command + Пробел, затем ввести Терминал в поле поиска Spotlight);
* Вводим в Терминал: `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`
* Нажимаем Enter;
* В процессе установки Homebrew, может потребоваться ввод пароля;
* После установки Homebrew внизу Терминала появится текст ==> Next steps.
#### 2. При установке на Mac с процессорами Intel:
* Вводим в Терминал: `echo >> ~/.zprofile`
* Нажимаем Enter;
* Вводим в Терминал: `echo 'eval "$(/usr/local/bin/brew shellenv zsh)"' >> ~/.zprofile`
* Нажимаем Enter;
* Вводим в Терминал: `eval "$(/usr/local/bin/brew shellenv zsh)"`
* Нажимаем Enter.
#### 2.1. При установке на Mac с процессорами Apple Silicon:
* Вводим в Терминал: `echo >> ~/.zprofile`
* Нажимаем Enter;
* Вводим в Терминал: `echo 'eval "$(/opt/homebrew/bin/brew shellenv zsh)"' >> ~/.zprofile`
* Нажимаем Enter;
* Вводим в Терминал: `eval "$(/opt/homebrew/bin/brew shellenv zsh)"`
* Нажимаем Enter.
#### 3. Устанавливаем пакеты ideviceinstaller, minizip и powershell:
* Вводим в Терминал: `brew install ideviceinstaller minizip powershell`
* Нажимаем Enter.
#### 3.1 Альтернативная установка PowerShell:
* Повторяем шаги 1-2 из предыдущего пункта;
* Переходим по ссылке для загрузки PowerShell:  
[Ссылка для загрузки PowerShell](https://github.com/PowerShell/PowerShell/releases)
* Находим версию PowerShell;
* Нажимаем Show all assets;
* Загружаем файл: powershell-@-osx-x64.pkg (для Mac с процессорами Intel) или powershell-@-osx-arm64.pkg (для Mac с процессорами Apple Silicon);
* Производим установку powershell-@-osx-x64.pkg (для Mac с процессорами Intel) или powershell-@-osx-arm64.pkg (для Mac с процессорами Apple Silicon);
* Вводим в Терминал: `brew install ideviceinstaller minizip`
* Нажимаем Enter.
#### Примечание:
* На macOS Big Sur/Catalina необходимо установить PowerShell 7.3.12:  
[Ссылка для загрузки PowerShell 7.3.12](https://github.com/PowerShell/PowerShell/releases/tag/v7.3.12)
* Для обновления Homebrew и всех компонентов вводим в Терминал: `brew update && brew upgrade && brew cleanup` и нажимаем Enter.

## Как использовать (macOS):
#### 1. Распаковываем архив IPA_Downloader.zip любым архиватором;
* Вводим в Терминал: `chmod +x ` (с пробелом после x) и перетаскиваем файл Start_IPA_Downloader.command на Терминал;
* Нажимаем Enter.
#### 2. Дважды кликаем по файлу Start_IPA_Downloader.command;
* В первый раз macOS заблокирует запуск Start_IPA_Downloader.command;
* В появившемся окне "Файл "Start_IPA_Downloader.command" нажимаем "Готово";
* Нажимаем на логотип Apple () в левом верхнем углу экрана и выбираем "Системные настройки...";
* В левой боковой панели прокручиваем вниз и выбираем вкладку "Конфиденциальность и безопасность";
* Прокручиваем правую часть экрана вниз до раздела "Безопасность";
* В пункте "Файл Start_IPA_Downloader заблокирован для защиты Вашего Mac" нажимаем на кнопку "Все равно открыть";
* В появившемся окне "Открыть файл "Start_IPA_Downloader" нажимаем "Все равно открыть";
* Вводим пароль от вашего Mac или прикладываем палец к Touch ID;
* При необходимости еще раз дважды кликаем по файлу Start_IPA_Downloader.command.
#### 3. При первом запуске потребуется первоначальная настройка:
* Выбираем язык;
* Нажимаем Enter;
* При наличии обновления выбираем, перейти на GitHub для загрузки новой версии скрипта или продолжить работу с текущей версией;
* Нажимаем Enter.
#### 4. По умолчанию скрипт запускается в режиме IPA_Installer:

#### 5. После перехода в режим IPA_Downloader:
* Выбираем версию ipatool (ipatool-cpp или ipatool-go);
* Нажимаем Enter;
* Вводим Аккаунт Apple (Enter email:);
* Нажимаем Enter;
* Вводим пароль (Enter password:);
* Нажимаем Enter;
* На устройстве нажимаем Разрешить и запоминаем код двухфакторной аутентификации (2FA);
* Если код двухфакторной аутентификации (2FA) автоматически не пришел, то на устройстве включаем режим полета, переходим в Настройки-Аккаунт Apple-Вход и безопасность-Получить код проверки (это и есть код двухфакторной аутентификации (2FA)); 
* Вводим код двухфакторной аутентификации (Enter 2FA code:);
* Нажимаем Enter;
* Вводим пароль от Mac;
* Нажимаем Разрешать всегда;
* Вводим необходимую команду;
* Нажимаем Enter.

  * Устанавливаем PowerShell: `sudo dnf install powershell`
  * Устанавливаем утилиты для работы с iOS: `sudo dnf install ideviceinstaller usbmuxd`
  * Включаем службу usbmuxd: `sudo systemctl enable --now usbmuxd`

## Описание команд IPA_Installer:

* Приложения должны находиться по пути IPA_Downloader/Apps;

* Скрипт осуществит переход на страницу CloudTips.
#### 4. Сменить язык (Change Language):
* Скрипт осуществит смену языка скрипта.
#### 5. Перейти в IPA_Downloader:
* Скрипт осуществит смену режима на IPA_Downloader.

## Расшифровка ошибок:
* Download error: HTTP request failed: Timeout was reached - Не удалось подключиться к серверам Apple, проверьте Ваше интернет-соединение.
* Error: license is required - Приложение не было приобретено на этом Аккаунте Apple ранее.
* Purchase error: app not found - Покупка приложения не удалась, так как приложение удалено из App Store.
* Purchase error: item is temporarily unavailable - Приложение не было приобретено на этом Аккаунте Apple ранее, покупка не удалась, так как приложение удалено из App Store.
* No device found - Устройство не найдено. Убедитесь, что драйвер AppleMobileDeviceSupport64 установлен (актуально для Windows).
* WARNING: could not locate Payload/App.app/SC_Info/App.sinf in archive! - В устанавливаемом ipa файле не найдена подпись приложения.
* Error: anisette exited with code 1 - check that anisette binary is working. iTunes Not Found (0) - Не установлен iTunes с сайта Apple.
* Error: anisette exited with code 1 - check that anisette binary is working. iCloud Not Found (1) - Не установлен iCloud с сайта Apple.
* Login error: GSA SRP exception: GSA complete error -27952: Update iCloud for Windows to the latest version to sign in - Необходимо отключить расширенную защиту данных по пути Настройки-Аккаунт-iCloud-Расширенная защита данных.
* Если после установки приложение сразу сворачивается при запуске, войдите в App Store под аккаунтом, с которого оно было загружено, и установите любое бесплатное/платное приложение. После этого запустите проблемное приложение снова.
